# Compact exact symmetry and completion improvements

## Representation and group action

An equation system fixes the duality involution `d` and partitions all nonunit
triples `(i,j,k)` into the Frobenius-reciprocity orbits representing the variables
`N_ij^k`. The relabelling group consists of every permutation `q` fixing the unit
and satisfying `q d = d q`. If there are `f` self-dual nonunit labels and `p` dual
pairs, its order is `f! 2^p p!`.

The historical positive `np` file format lists the action of every group element
on the variables. The new sentinel `np=-1` replaces that table by the duality
vector and one representative triple for each variable, in its original order.
The loader reconstructs each orbit using

```
(i,j,k) -> (d(i),k,j), (k,d(j),i).
```

It checks the duality involution, disjointness of the orbits and coverage of all
nonunit triples. Thus it obtains the same variable action by looking up the orbit
of `(q(i),q(j),q(k))`. The negative sentinel also makes historical readers fail
instead of silently treating a compact system as having no symmetries. The
legacy `np=0` convention remains supported for symmetry-free synthetic audit
systems; it is not used for the delivered fusion-ring systems.

## Exact acceptance without storing the group

For a complete parameter vector `v`, the criterion is unchanged:

```
v <= (v[q(orbit_0)], ..., v[q(orbit_(nv-1))]) for every q commuting with d.
```

`canonical_complete` searches this group by partial bijections. When assigning
`q(x)=y`, it simultaneously assigns `q(d(x))=d(y)`; it uses only unused images of
the same duality type. Every such partial bijection extends to a full group
element, because the remaining self-dual labels and remaining pairs have equal
cardinalities on both sides.

The search examines coefficients in the original parameter order. Whenever all
three images in the next representative triple are known, that coefficient is
known throughout the current permutation subtree. If it is larger than the
corresponding coefficient of `v`, the entire subtree cannot disprove minimality
and is skipped. If it is smaller, any extension disproves minimality, and the
vector is rejected. Equal coefficients advance to the next variable. An unknown
image causes branching over all admissible images. This proves equivalence with
comparison against the full explicit permutation table.

`canonicalize(v)` uses the same branching and comparison with an incumbent
vector, updating that vector at complete assignments. It returns the same
lexicographic minimum as the historical explicit loop. The weighted self-dual
unfolding uses this function.

## Safe partial-domain propagation

If the group order is at most 4096, the solver retains all its inequalities for
partial propagation. For larger groups it retains the permutations generated by
individual swaps of self-dual labels, reversals of pairs, swaps of pairs, and all
products of two such generators. These are genuine group elements, so their lex
inequalities are necessary for the full lexicographic minimum. Omitting other
inequalities can only retain additional search branches; it cannot remove a
canonical solution. The complete group test above is performed before every
emission, both from recursive completion and direct candidate acceptance.

For the rank-nine self-dual system this reduces the stored partial comparisons
from 40,320 to 351. For rank eleven it avoids an explicit table with 3,628,800
rows of 220 variable images. No claim that the chosen partial inequalities alone
characterize a canonical vector is made or used.

## Exact algebraic improvements

At multiplicity bound one, every variable satisfies `x^2=x`. The loader therefore
replaces square monomials by linear monomials and combines equal monomials. This
preserves each equation pointwise on its full integer search domain. Constants
are multiplied by the weighted unit coefficient before collection, preserving
the weighted self-dual use as well. Higher multiplicity bounds retain the
original polynomials.

Gaussian elimination still computes the same necessary congruences modulo
257. It now skips pivot entries that are zero when updating another row; those
updates would subtract zero. Modular inverses are computed by the standard
prime-field recurrence rather than a quadratic exhaustive loop. Neither change
alters the elimination or any finite-domain support condition.

Parallel workers copy the already parsed seed system once per worker instead of
reparsing the same file. Their domains, trails, counters and scratch buffers are
separate. Frontier boxes are unchanged and remain disjoint. Both general
frontends flush standard output before reporting successful stream completion.

## Limits and evidence

The general solver accepts ranks 4 through 11 and bounds 1 through 15, with
variable/equation safety caps of 256 and 8192. All delivered systems fit these
caps. The 16-value domains fit the existing unsigned masks; 257 exceeds every
domain value; polynomial evaluations retain 64-bit signed integer arithmetic.

Existing randomized equation-support and modular-elimination audits were rerun
after these changes. Explicit-versus-compact symmetry comparisons and exact
enumerator-output comparisons supplement those audits. Evidence for the general
solver is in `benchmarks/evidence/rank11_extension/general_solver/`; further
independent audits and complete end-to-end runs are documented by the release.

Benchmark timings depend on machine load. A timed-out run is recorded as such
and is not a completed census, even if its log includes provisional discoveries.
